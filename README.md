# Pesquisa de Opinião - TudoWeb

Este repositório contém a solução desenvolvida para a atividade prática de programação em Python, com o objetivo de coletar e analisar dados de uma pesquisa de satisfação de atendimento ao cliente.

## Sobre o Projeto
O programa simula uma pesquisa de opinião realizada com clientes da empresa de marketing **TudoWeb**. Ele utiliza estruturas de repetição e de decisão para:
* Coletar o nome, a idade e a opinião de 50 entrevistados (ou 10 para testes rápidos).
* Validar as entradas do usuário.
* Contabilizar e exibir a quantidade total de respostas **EXCELENTE** e **RUIM**.

## Tecnologias Utilizadas
* **Linguagem:** Python
